# Super User

Tiny Windows utility that runs programs as `NT AUTHORITY\SYSTEM`.

- No arguments: double-click to open `cmd.exe` as SYSTEM.
- With an argument: drag and drop a program onto the exe, or pass it on the command line, to run that program as SYSTEM.

## Releases

Each push to `main` builds a Windows release and publishes it as a zip containing the exe. See the [Releases](../../releases) page for downloads.
